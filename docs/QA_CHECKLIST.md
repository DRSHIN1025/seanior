# SEA;NIOR QA 체크리스트 (QA_CHECKLIST)

본 체크리스트는 SEA;NIOR 서비스의 기능성, 안정성, 시니어 접근성 및 보안 무결성을 검증하기 위한 항목들입니다.

---

## 1. 폼 입력 및 유효성 검증 (Validation)
- [x] **TC-VAL-01**: 제목 미입력 또는 공백 문자만 입력 시 적절한 한국어 에러 메시지 표시
- [x] **TC-VAL-02**: 제목이 80자를 초과할 때 입력 차단 및 경고
- [x] **TC-VAL-03**: 이야기(사연) 미입력 또는 공백만 입력 시 저장 차단
- [x] **TC-VAL-04**: 이야기가 2,000자를 초과할 때 검증 에러 반환
- [x] **TC-VAL-05**: 표현 방식(5종) 미선택 시 기본값 적용 및 유효 enum 검사
- [x] **TC-VAL-06**: 수정 요청 시 빈 텍스트 제출 차단 (최소 1자 이상 필수)

---

## 2. 파일 업로드 및 보안 검사 (File & Storage)
- [x] **TC-FILE-01**: 파일 없이 텍스트 사연만으로 정상 등록 가능
- [x] **TC-FILE-02**: 허용된 포맷(JPG, PNG, WEBP, MP4)의 정상 업로드 및 미리보기
- [x] **TC-FILE-03**: 단일/총합 3MB 초과 파일 첨부 시 클라이언트 및 서버에서 즉시 거부
- [x] **TC-FILE-04**: 확장자/MIME을 변조한 위장 파일(HTML/SVG -> PNG) 매직 바이트 검사로 차단
- [x] **TC-FILE-05**: 파일 교체 시 기존 Storage 파일 삭제 및 정리 확인
- [x] **TC-FILE-06**: DB 저장 실패 시 업로드된 새 파일 자동 롤백 삭제 확인

---

## 3. 상태 전이 및 승인 비즈니스 규칙 (State Lifecycle)
- [x] **TC-STAT-01**: 신규 등록 직후 상태가 `submitted`(제작 요청됨)인지 확인
- [x] **TC-STAT-02**: 제작 결과(소개글/파일) 등록 시 상태가 `ready`(확인해 주세요)로 전환
- [x] **TC-STAT-03**: 결과물이 전혀 없는 상태에서 최종 승인 버튼 클릭 시 승인 불가 차단
- [x] **TC-STAT-04**: 결과물 확인 체크박스 선택 후 최종 승인 시 `approved` 및 `approved_at` 기록
- [x] **TC-STAT-05**: 승인 완료된 레코드의 원본 내용(제목/이야기/파일) 수정 시 승인 해제 및 `submitted` 리셋
- [x] **TC-STAT-06**: 준비된 결과에 대해 수정 요청 제출 시 `revision_requested`로 전환 및 수정 사유 저장

---

## 4. 동시성 및 에러 처리 (Concurrency & Fault Tolerance)
- [x] **TC-CON-01**: 두 개의 탭에서 동일 레코드 편집 시, 이전 탭의 오래된 수정 내용 덮어쓰기 차단 (`updated_at` 기반 충돌 감지)
- [x] **TC-CON-02**: 존재하지 않는 UUID 상세 페이지 접근 시 404 Not Found 화면 정상 표시
- [x] **TC-CON-03**: Supabase 미설정 상태에서 랜딩 페이지 정상 로딩 및 데이터 화면 설정 가이드 안내
- [x] **TC-CON-04**: 레코드 삭제 시 확인 모달 표시 및 DB/스토리지 연동 정리

---

## 5. UI/UX 및 시니어 접근성 (Accessibility & Responsiveness)
- [x] **TC-UI-01**: 모바일 기준 너비 390px에서 가로 스크롤 넘침 없이 완벽하게 레이아웃 표시
- [x] **TC-UI-02**: 데스크톱 1440px 화면에서 적절한 최대 너비(max-w-5xl) 유지 및 중앙 정렬
- [x] **TC-UI-03**: 주요 액션 버튼이 56px 표준 높이를 유지하여 시니어 터치 편의성 보장
- [x] **TC-UI-04**: 한글 폰트가 깨지거나 네모(tofu)로 표시되지 않고 깔끔한 고딕체 렌더링
- [x] **TC-UI-05**: Web Speech API 지원 브라우저에서 '말로 들려주기' 마이크 정상 동작 및 텍스트 대체 수단 상시 제공

---

## 6. 보안 검증 (Security)
- [x] **TC-SEC-01**: `SUPABASE_SERVICE_ROLE_KEY`가 클라이언트 번들에 노출되지 않음 (`server-only` 모듈 적용)
- [x] **TC-SEC-02**: `.env.local`이 `.gitignore`에 등록되어 Git 저장소에 커밋되지 않음

---
