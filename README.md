# SEA;NIOR - 시니어 창작 콘텐츠 서비스 (미션 5)

> **시니어의 경험과 재능(그림, 공예, 요리, 악기 등)을 콘텐츠로 만들어 세상과 연결하고 지속적인 창작 활동을 지원하는 서비스**

본 브랜치(`mission-5`)는 **[신득렬]-미션5** 제출물로서, 61~74세 액티브 시니어를 위한 맞춤형 사용자 경험(UX)과 반응형 디자인 시스템, 인터랙티브 컴포넌트를 탑재한 **독립 실행 가능한 랜딩 페이지**를 포함합니다.

---

## 1. 제품 정체성 및 해결 과제

- **브랜드명**: **`SEA;NIOR`**
- **타깃 페르소나**: 61~74세 시니어 창작자 (스마트폰, 카카오톡, 유튜브 시청은 익숙하나 자막·썸네일·영상 편집과 업로드가 어려운 분들)
- **창업 배경 스토리**:
  73세에 처음 붓을 잡고 고향 풍경을 그리신 아버지의 이야기. 자녀의 도움으로 유튜브에 영상을 올렸을 때 200명 이상의 구독자와 뜨거운 응원을 받으며 삶의 활력을 얻으셨으나, 자녀의 편집 지원이 중단되자 콘텐츠 업로드도 멈추었습니다.
- **핵심 솔루션**:
  “시니어에게 복잡한 영상 편집기를 가르치는 대신, **선택하고 이야기하고 확인만 하면** 창작 활동이 지속되도록 돕자.”

```
[고르GO] 사진/영상 선택  →  [말하GO] 사연·분위기 전달  →  [확인하GO] 초안 검토 및 승인
```

## 3. 시니어 접근성 및 반응형 디자인 시스템

1. **56px 시니어 터치 규격**:
   - 모바일 기기 조작 시 손가락 떨림이나 부정확한 터치를 감안하여 주요 액션 버튼의 최소 높이를 `56px`(`min-h-[56px]`) 이상으로 통일.
2. **가독성 및 고대비 색상 팔레트**:
   - 배경(`neutral-50`)과 본문 텍스트(`neutral-900`) 간 충분한 명도비(4.5:1 이상)를 확보하고, 불명확한 회색 텍스트 지양.
   - Noto Sans KR, Pretendard, 시스템 고딕 스택을 활용하여 모바일과 데스크톱 모두에서 한글 글자 깨짐(tofu) 방지.
3. **반응형 뷰포트 지원**:
   - **모바일 (390px)**: 한 손 조작을 위한 상단 고정 헤더 및 하단 네비게이션 탭바 제공, 가로 넘침(overflow) 원천 차단.
   - **데스크톱 (1440px)**: `max-w-5xl` 중앙 정렬 컨테이너로 시각적 안정감과 여백을 최적화.

## 4. 실제 JavaScript 인터랙션 구현

- **3단계 UX 인터랙티브 탭 (`activeStep`)**:
  - `1. 고르GO` $\rightarrow$ `2. 말하GO` $\rightarrow$ `3. 확인하GO` 탭 클릭 시 각 단계의 상세 설명과 프리뷰 카드가 동적으로 전환.
- **자주 묻는 질문(FAQ) 아코디언 토글 (`openFaqIndices`)**:
  - 부드러운 애니메이션과 함께 질문 클릭 시 상세 답변이 펼쳐지는 다중 열림 지원 아코디언.
- **모바일 햄버거 메뉴 토글 (`mobileMenuOpen`)**:
  - 모바일 뷰포트에서 네비게이션 서랍 메뉴를 열고 닫을 수 있는 인터랙티브 상태 관리.
- **경로 무결성**:
  - 외부 백엔드(Supabase) 없이도 100% 독립 실행 가능하며, 모든 CTA 버튼이 페이지 내 유효한 앵커 섹션(`#process`, `#story`, `#faq` 등)으로 연결되어 404 깨진 링크가 발생하지 않음.

## 6. 서비스 경계 및 정직한 기능 표현

- **AI 및 자동화 범위 안내**:
  - 본 서비스는 시니어 사용자의 복잡한 편집 진입 장벽을 낮추기 위해 **'선택-구술-확인'**의 쉬운 사용자 인터페이스를 제공하는 서비스입니다.
  - 외부 인스타그램/유튜브 API 직접 게시는 시니어 사용자의 개인정보 보호 및 최종 동의를 위해 후속 연동 과제로 분리되어 있으며, '자동 게시가 구현 완료되었다'고 과장하여 표현하지 않습니다.

## 7. 실행 및 검증 명령어 (Supabase 없이 독립 실행 가능)

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행 (별도 환경변수 없이 즉시 동작)
npm run dev

# 3. 정적 타입 검사
npx tsc --noEmit

# 4. 정적 린트 검사
npm run lint

# 5. 프로덕션 빌드 검사
npm run build
```
